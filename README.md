
The objective of this task is to understand the relationship between hourly wages and usual 
weekly hours worked. We want to check whether the inverted u-shape graph obtained in 
previous works also exists in more recent data.  The dataset used is IPUMS outgoing 
rotational group from the year 2019. We restrict the sample as described in the paper.  
The method used is an OLS regression model, with suitable socio-economic controls. The 
dependent variable is log of hourly wages while the main independent variable of interest is a 
categorical variable of weekly hours worked. The weekly hours worked are binned together 
in 5-hour slots and top coded at 70. Thus, the coefficients measure the percentage increase in 
hourly wages associated with a 5-hour increase in weekly working hours, ceteris paribus. The 
values predicted by this regression are hence plotted on the graph.
